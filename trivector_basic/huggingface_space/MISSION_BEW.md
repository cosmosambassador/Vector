# BEW Tech Language — Project Mission

**Basic English Words. Real technical meaning. More people able to take part.**

Human authority: TJ Morris. Home: AISI / MC-6 Grim / TJTM Grimoire.
Date: 24 October 2026. Status: RRRR working mission; formal canon approval pending.

## Mission

Build an open-source language bridge so students, GED learners, people with technical certificates, field crews, college graduates, engineers and AI users can share technical knowledge without needless wordiness.

BEW is a third way to express a technical idea, alongside everyday wording and formal technical wording. It is a project vocabulary and explanation style, not a new natural language or a replacement for source languages.

## Three expression options

| Option | Purpose | Example |
| --- | --- | --- |
| Everyday wording | Preserve what a person says | “The crew checks how well the radio works here.” |
| Technical wording | State the precise engineering concept | “Measure radio coverage and record the test conditions.” |
| BEW | Keep the meaning clear with basic words | “Test the radio here. Record where, when and how.” |

These are explanation examples, not equivalent measured results. A BEW explanation must retain any units, limits, uncertainty and source details needed for the task. Shorter wording is useful only when the meaning survives.

## Language access

Keep the original text and its language. Offer BEW as an English explanation. Add reviewed labels in other languages when available. Mark machine drafts. Leave unknown terms blank. Preserve separate meanings, including Coptic oube, geometric cube and the proposed AISI Oube Gap.

BEW explains; OWL structures concepts; YAML and JSON carry records; Python and C++ run the basic software. A shared prompt can carry the record to an LLM; no automatic service connection or equivalent output across models is implied.

## Education and skill

Recognize learning in schools, GED programs, technical certificates, apprenticeships, job sites and college. Make technical work easier to understand across those paths. This project does not award credentials or replace an employer's skill assessment.

## GitHub and Hugging Face

GitHub is the source and review home. Hugging Face is the intended public demo home; the prepared Space files need an authorized write route before upload. The third option is BEW expression, not a third hosting service.

## First acceptance checks

- A learner can explain a term back without losing its key meaning.
- An engineer can find the original term, units, source and uncertainty.
- A software reader can load the same concept ID from the structured record.
- A reviewer can tell sourced text, machine drafts and project hypotheses apart.

These are proposed acceptance checks, not achieved study results. Human comprehension testing remains pending. Existing local code test results are in TEST_RESULTS.md.
