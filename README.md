# Vector

Quad Vector Universal Operator Summary

## Supported Cartography & Data Science Tasks

### Microsoft
- **Azure Maps & Geospatial Services**: Spatial analysis, routing, geocoding, and weather data integration.
- **Planetary Computer**: Environmental & geospatial data analytics, satellite imagery processing, and land-use mapping.
- **Power BI & Synapse Analytics**: Geospatial visualization, spatial dashboards, and big data spatial telemetry.

### GitHub
- **GeoJSON & TopoJSON Visualization**: Native rendering and version-controlled geospatial vector datasets.
- **GitHub Actions for Spatial Pipelines**: Automated GIS workflows, ETL data processing, and validation scripts.
- **Collaborative Open-Source GIS**: Code repository management for spatial data algorithms and models.

### Hugging Face
- **Geospatial AI & Remote Sensing Models**: Satellite image segmentation, land-cover classification, and object detection.
- **Spatial NLP & Geo-Entity Extraction**: Location extraction, place name disambiguation, and topographic parsing.
- **Datasets & Model Hub**: Hosting, sharing, and fine-tuning GIS foundation models and raster datasets.

- **Lexicon**: Standardized vocabulary for message schemas, interface declarations, and telemetry protocol mapping.
